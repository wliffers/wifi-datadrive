## 4. What this means for publishing

- **MIT for the project is compatible** with all licences above. None of them is copyleft for
  the firmware (Mbed TLS is taken under Apache-2.0, not GPL; the GCC runtime has the runtime
  exception).
- **Files that must keep their header or licence file:** `firmware/components/st7735/*` with
  `LICENSE.LILYGO`, `firmware/components/display/font5x7.c` with `LICENSE.Adafruit_GFX`. Do not
  remove or rewrite those headers.
- **Binary releases (`.bin` files, the browser flasher) must ship the notices.** BSD-2/BSD-3
  (Adafruit, lwIP, wpa_supplicant, TLSF), ISC, MIT (TinyUSB, FreeRTOS, Nayuki QR code, LILYGO)
  and Apache-2.0 (ESP-IDF, Mbed TLS, Espressif components) all ask that the copyright notice and
  licence text accompany binary copies. The release workflow (`.github/workflows/release.yml`)
  therefore attaches `LICENSE`, this file and a `licenses.zip` with the licence texts collected
  from ESP-IDF and the managed components (`.github/scripts/collect_licenses.py`). If you build
  and hand out binaries yourself, include the same.
- **Apache-2.0 NOTICE files:** none of the Apache-2.0 components used here ships a `NOTICE`
  file (checked: the four managed components, the ESP-IDF v5.5.6 root and Mbed TLS; the only
  `NOTICE` in ESP-IDF belongs to OpenThread, which this firmware does not use). If a future
  version adds one, its content must be passed on.
- **Mascot artwork:** the mascot "LIO" (name, character, artwork) is the owner's own work and is NOT covered by the MIT licence; see `LICENSE-LIO.md`.
- **LILYGO factory image:** `backup/*.bin` (LILYGO factory firmware, flash dumps) is
  git-ignored and must not be published; it is LILYGO's firmware and a flash dump can contain
  Wi-Fi credentials.
