WiFi DataDrive

Firmware für den LILYGO T-Dongle-S3 in der Variante mit LCD (ESP32-S3, 16 MB Flash): USB-Stick für 3D-Drucker und PCs mit Dateiverwaltung im Browser über WLAN. Andere Varianten (T-Dongle-S3 Plus, Dual) sind nicht getestet.

Firmware for the LILYGO T-Dongle-S3, LCD variant (ESP32-S3, 16 MB flash): a USB stick for 3D printers and PCs with a browser file manager over Wi-Fi. Other variants (T-Dongle-S3 Plus, Dual) are not tested.

1. Was du brauchst

  • Chrome oder Edge auf einem PC oder Mac (Web Serial). Laut ESP Web Tools gehen auch Firefox und Chrome unter Android; das ist hier nicht geprüft. iPhone und iPad gehen nicht.
  • Den T-Dongle-S3 (LCD-Variante) und einen freien USB-A-Anschluss (oder Adapter).
  • Optional eine microSD-Karte (FAT32). Ohne Karte nutzt der Stick seinen internen Speicher (ca. 11 MB).

2. Dongle in den Download-Modus bringen

  1. Dongle abziehen.
  2. Die Taste am Dongle (BOOT) gedrückt halten.
  3. Dongle mit gedrückter Taste einstecken, Taste nach etwa 2 Sekunden loslassen.

Läuft schon WiFi DataDrive, geht es auch so: Taste 5 bis 10 Sekunden halten und dann loslassen (Wartungsmodus; laut Quelltext, am Gerät noch nicht als eigener Test geprüft).

3. Installieren

  1. Oben auf Installieren klicken und im Fenster den Anschluss des Dongles wählen. Er heißt meist „USB JTAG/serial debug unit“ (USB-ID 303A:1001).
  2. Die Seite fragt (auf Englisch, „Erase device“), ob das Gerät gelöscht werden soll:
    • Erstinstallation (Werks-Firmware von LILYGO oder unbekannter Stand): Löschen wählen. Das löscht den ganzen internen Flash, auch Dateien im internen Speicher.
    • Ohne Löschen wird nur der vordere Teil überschrieben (Bootloader, Partitionstabelle, Einstellungen, Firmware). Ob Dateien im internen Speicher dabei erhalten bleiben, ist nicht geprüft. Vorher sichern.
  3. Warten, bis die Seite „fertig“ meldet. Dann den Dongle abziehen und wieder einstecken. Ohne das bleibt er nach dem manuellen Download-Modus im Download-Modus hängen (beobachtet).

4. Was mit vorhandenen Daten passiert

  • In jedem Fall zurückgesetzt: Benutzer (wieder admin / admin), gespeicherte WLANs, vertraute Geräte, Einstellungen und ein HTTPS-Zertifikat des Sticks. Ein früher installiertes Zertifikat muss nach dem Einschalten von HTTPS neu installiert werden.
  • Die microSD-Karte wird beim Flashen nicht beschrieben. Eine verschlüsselte Karte bleibt verschlüsselt; Laufwerks-Passwort und Wiederherstellungsschlüssel gelten laut Quelltext weiter (nach einem Neu-Flashen nicht geprüft).
  • Nur ein Update einer laufenden WiFi DataDrive? Dafür ist die Datei …-app.bin aus dem Release für das Update in der Weboberfläche gedacht (Einstellungen → System); sie behält Einstellungen und Dateien. Dieser Weg ist am Gerät noch nicht geprüft.

5. Erster Start

  1. Ohne gespeichertes WLAN öffnet der Dongle das Einrichtungs-WLAN DataDrive-XXXX. Das Passwort steht auf dem Display.
  2. Mit dem Handy oder PC verbinden. Öffnet sich die Seite nicht von selbst, im Browser http://192.168.4.1 aufrufen.
  3. Anmelden mit admin / admin. Die Oberfläche verlangt sofort ein neues Passwort; admin ist dabei nicht erlaubt.
  4. Unter Einstellungen → Netzwerk das Heim-WLAN eintragen. Danach ist der Stick unter http://datadrive.local oder der IP vom Display erreichbar.

Passwörter gehen ohne HTTPS unverschlüsselt durchs WLAN. HTTPS lässt sich in den Einstellungen einschalten. Mehr dazu und der vollständige Prüfstand: README.

1. What you need

  • Chrome or Edge on a PC or Mac (Web Serial). According to ESP Web Tools, Firefox and Chrome on Android work too; that is not tested here. iPhone and iPad do not work.
  • The T-Dongle-S3 (LCD variant) and a free USB-A port (or an adapter).
  • Optionally a microSD card (FAT32). Without a card the stick uses its internal storage (about 11 MB).

2. Put the dongle into download mode

  1. Unplug the dongle.
  2. Press and hold the button on the dongle (BOOT).
  3. Plug the dongle in while holding the button, release it after about 2 seconds.

If WiFi DataDrive is already running, this also works: hold the button for 5 to 10 seconds, then release it (maintenance mode; according to the source code, not yet tested on the device as a separate test).

3. Install

  1. Click Install above and pick the dongle's port in the dialog. It is usually called "USB JTAG/serial debug unit" (USB ID 303A:1001).
  2. The page asks whether to erase the device ("Erase device"):
    • First install (LILYGO factory firmware or unknown state): choose erase. This erases the whole internal flash, including files in the internal storage.
    • Without erasing only the first part is overwritten (bootloader, partition table, settings, firmware). Whether files in the internal storage survive is not tested. Back them up first.
  3. Wait until the page reports that it is done. Then unplug the dongle and plug it in again. Otherwise it stays in download mode after the manual download mode (observed).

4. What happens to existing data

  • Always reset: users (back to admin / admin), saved Wi-Fi networks, trusted devices, settings and the stick's HTTPS certificate. A previously installed certificate has to be installed again after HTTPS is switched on.
  • The microSD card is not written by the flasher. An encrypted card stays encrypted; the drive password and recovery key keep working according to the source code (not tested after re-flashing).
  • Only updating a running WiFi DataDrive? The …-app.bin file of the release is meant for the update in the web UI (Settings → System); it keeps settings and files. That path is not yet tested on the device.

5. First start

  1. Without a saved Wi-Fi network the dongle opens the setup network DataDrive-XXXX. The password is shown on the display.
  2. Connect with a phone or PC. If the page does not open by itself, go to http://192.168.4.1.
  3. Sign in with admin / admin. The UI asks for a new password right away; admin is not allowed.
  4. Add your home Wi-Fi under Settings → Network. The stick is then reachable at http://datadrive.local or at the IP shown on the display.

Without HTTPS, passwords travel unencrypted over Wi-Fi. HTTPS can be switched on in the settings. Details and the full test status: README (English).
